# Manual Installation (Debian 13)

The following fonts and programs are not available in the Debian 13 repositories and must be downloaded manually from their official websites.

## Fonts

Download and install the following fonts to:

`~/.local/share/fonts/`

- JetBrains Mono
- Source Han Sans SC

Then refresh the font cache:

```sh
fc-cache -fv
```

## Programs

Download and install the following programs to:

`~/.local/bin/`

- chafa
- lf
- distrobox

Ensure the downloaded files are executable.
